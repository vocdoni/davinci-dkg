# DAVINCI DKG contracts

Solidity contracts of [DAVINCI DKG](../README.md), built with Foundry (solc 0.8.28, via IR,
Cancun).

## Contracts

| Path | Purpose |
|---|---|
| `src/DKGRegistry.sol` | Operator keys and liveness (`registerKey`, `heartbeat`, `reactivate`, `reap`) |
| `src/DKGManager.sol` | Epoch lifecycle, pool keys, ciphertexts, partial and combined decryptions |
| `src/DKGAppManager.sol` | Application registration, organizer secret reveal, submission and decryption gates |
| `src/interfaces/` | Integration interfaces: full signatures, events and errors |
| `src/libraries/` | Shared types, sizes, protocol domains, BRLC transcript commitment, BabyJubJub arithmetic |
| `src/verifiers/` | Groth16 verifiers of the four circuits, generated by `cmd/circuit-compile` |
| `golang-types/` | Go bindings, generated by `go_bind.sh` |

The protocol and the role of each call are described in [docs/protocol.md](../docs/protocol.md);
the transcript encodings the contracts check are in [docs/pool-keys.md](../docs/pool-keys.md).

## Integrating

An application contract reads its key from `DKGAppManager` and submits to `DKGManager`:

```solidity
(uint256 x, uint256 y) = appManager.getApplicationKey(epochId, aid);          // PK_aid, reduced twisted Edwards form
uint16 index = manager.submitCiphertext(epochId, aid, c1x, c1y, c2x, c2y);    // emits CiphertextSubmitted
uint256 m = manager.getPlaintext(epochId, aid, index);                         // once the committee has combined it
```

The application itself is registered with `DKGAppManager.registerApplication`, and
`DKGManager.appManager()` returns the app manager's address. Import the interfaces from
`src/interfaces/`.

## Usage

```bash
forge build
forge test
forge test --gas-report
./go_bind.sh           # regenerate golang-types/ after changing a contract ABI
```

From the repository root, `make solidity-deploy` deploys the full suite through
`deploy_all.sh`; the variables it reads are listed in
[docs/deployments.md](../docs/deployments.md#deploying-your-own). `script/DeployAll.s.sol` is the
Foundry script it runs. `testnet/deploy.sh` deploys to the local testnet and the integration-test
chain.

The verifiers in `src/verifiers/` embed the verifying keys pinned in
`config/circuit_artifacts.go`; they are rewritten by `make circuits` and should not be edited by
hand.
